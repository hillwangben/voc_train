## 5. 容器运行

执行脚本:

```bash
cd /home/code/voc_train/speech_train_preset
./scripts/run_local_container_validation.sh
```

脚本采用 `docker create` 后 `docker start --attach`,不会在执行结束时删除容器。
容器内顺序执行:

```bash
./train.sh
SAVE_DIR=/workspace/output/evaluate ./eval.sh
```

关键环境变量:

```text
TASK_TYPE=asr
BACKEND=vosk_small
DATA_DIR=/workspace/input
MODEL_DIR=/workspace/model
SAVE_DIR=/workspace/output
```

输出目录挂载:


## 7. 保留容器的复核与复用

查看保留状态和日志:

```bash
docker ps -a --filter name=speech-train-asr-validation
docker logs speech-train-asr-validation
docker inspect speech-train-asr-validation
```

重新启动保留容器会按原挂载和原命令再次执行训练、评估:

```bash
docker start --attach speech-train-asr-validation
```

重新运行验证脚本时,脚本会删除同名旧容器并创建新的保留容器。也可覆盖名称
和输出目录:

```bash
CONTAINER_NAME=speech-train-asr-validation-2 \
OUTPUT_DIR=/tmp/speech-validation \
./scripts/run_local_container_validation.sh
```
