# 语音类垂直训练资产包

本资产包参考“智能模型集成规范”和“资产包准备说明”，采用方案2：单一统一训练容器提供语音类模型训练、评估、适配和服务能力。

## 覆盖能力

1. 语音识别垂直训练
2. 复杂噪声下语音增强垂直训练
3. 跨信道连续语音识别垂直训练
4. 小语种连续语音识别垂直训练
5. 混合语种连续语音识别垂直训练
6. 声纹识别垂直训练
7. 语音智能交互垂直训练
8. 多语言语音翻译垂直训练
9. 语音转写垂直训练
10. 语音纠错垂直训练

## 目录结构

```text
speech_train_preset/
├── alg/speech_train_all_in_one/
├── env/speech_train_all-env/
├── dataset/speech_train_sample-dataset/
├── model/speech_train_base-model/
└── docs/
```

## 交付说明

- `alg/`：统一语音训练算法工程，包含 `config.yaml`、训练、评估、模型适配、服务启动脚本。
- `env/`：统一语音训练环境镜像资产描述，实际交付时需放置镜像 tar 包。
- `dataset/`：示例数据集资产描述，实际交付时需放置压缩后的语音数据包。
- `model/`：基础模型资产描述，实际交付时需放置模型压缩包。
- `docs/`：交付清单、镜像构建说明、数据规范和验收说明。
