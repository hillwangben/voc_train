# 语音类垂直训练容器交付物清单

## 1. 交付策略

采用方案 2:一个统一语音训练容器承载全部 10 类语音垂直训练能力。
平台通过算法包 `config.yaml` 中的 `task_type` 参数选择具体训练任务,
通过 `BACKEND` 环境变量或 `--backend` 参数选择真实模型后端
(默认按 `docs/open_source_cpu_models.json` 自动选有真实权重的后端)。

**已 10/10 任务接入真实开源 CPU 后端**,`cpu_reference` 仅作降级备选。

## 4. 容器镜像

当前工程提供**离线构建包**(offline_container_build_package),非完整 Docker 镜像。

### 4.1 目标镜像命名(平台侧确认后)

| 字段 | 值 |
|---|---|
| Registry | `cetc-harbor.registry.com:30003` |
| 系统 | `ubuntu22.04` |
| Python | `3.10` |
| 算法库 | (无 CUDA,CPU-only) |
| 框架 | `torch2.1` |
| 自定义 tag | `speech-train-all-v1` |

完整 tag:
```text
cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1
```

如平台硬性要求 `10.0.64.41/engine/` 前缀,可重 tag:
```text
10.0.64.41/engine/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1
```

### 4.2 平台侧构建(两种模式)

**模式 A:Harbor 推送(完整镜像)**

```bash
docker build -t cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1 \
    env/speech_train_all-env
docker push cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1
```

**模式 B:离线 tar 导入**

```bash
docker save cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1 \
    | gzip > env/speech_train_all-env/speech_train_all-env.tar.gz
```

## 5. 10 类任务与默认真实后端

| task_type | 对应需求 | 默认真实后端 | 关键产物指标 |
|---|---|---|---|
| `asr` | 语音识别 | `vosk_small` | wer, cer |
| `noise_enhancement` | 复杂噪声语音增强 | `rnnoise` | snr_improvement, pesq_proxy, stoi_proxy |
| `cross_channel_asr` | 跨信道连续语音识别 | `vosk_small` | wer, cer, channel_metrics |
| `low_resource_asr` | 小语种连续语音识别 | `vosk_small` | wer, cer |
| `code_switch_asr` | 混合语种连续语音识别 | `sherpa_onnx_int8` | wer, cer, channel_metrics |
| `speaker_verification` | 声纹识别 | `speechbrain_ecapa` | eer_proxy, verification_accuracy |
| `speech_interaction` | 语音智能交互 | `vosk_small` + `minilm_intent` | intent_accuracy, slot_f1 |
| `speech_translation` | 多语言语音翻译 | `vosk_small` + `opus_mt_tiny` | bleu_proxy, chrf_proxy |
| `transcription` | 语音转写 | `vosk_small` | wer, cer, channel_metrics |
| `speech_correction` | 语音纠错 | `vosk_small` + `pycorrector_kenlm` | correction_precision/recall/f1 |

> 默认后端由 `backends.py:default_backend_for_task()` 自动选择。
> 强制指定:`CPU_FLOW_BACKEND=vosk_small python3 scripts/cpu_flows/run_asr.py`
> 或 `python3 scripts/cpu_flows/run_asr.py --backend vosk_small`。

## 7. 平台入口

算法包提供四类平台任务入口(在 `alg/speech_train_all-alg/main/`)：

| 入口 | 用途 |
|---|---|
| `train.sh` | 训练入口 |
| `eval.sh` | 评估入口 |
| `convert.sh` | 模型格式转换 / 适配入口 |
| `service.sh` | 在线服务入口 |

启动时通过环境变量 `TASK_TYPE` 与 `BACKEND` 选择具体任务与后端。
详见 `docs/训练平台集成使用说明.md` §4-§7 与 `docs/验收说明.md` §4。

## 8. 自检与运行命令

```bash
# 1. 资产结构自检
python3 scripts/validate_asset_package.py
# 期望:asset-package-ok

# 2. 10 任务真实后端一键跑通
python3 scripts/run_all_cpu_tasks.py
# 期望:runs/all_cpu_tasks/summary.json

# 3. 单任务独立跑
python3 scripts/cpu_flows/run_<task_type>.py --output-root ../runs/cpu_flows

# 4. 单元测试
python3 -m unittest discover -s alg/speech_train_all-alg/main/tests -p 'test_*.py'
```
