# 语音训练数据集规范

## 1. 数据集压缩包

数据集以 zip 包形式提供，放置在数据集资产目录中：

```text
dataset/speech_train_sample-dataset/speech_train_sample-dataset.zip
```

平台或算法读取的数据集路径为压缩包解压后的根目录。

## 2. 推荐目录结构

```text
speech_train_sample-dataset/
├── audio/
│   ├── train/
│   ├── valid/
│   └── test/
├── labels/
│   ├── train.jsonl
│   ├── valid.jsonl
│   └── test.jsonl
└── metadata.json
```

## 3. 标注格式

推荐使用 JSON Lines，每行一条音频样本：

```json
{"utt_id":"utt_000001","audio":"audio/train/utt_000001.wav","text":"示例转写文本","language":"zh","speaker_id":"spk001","channel":"mic_1","noise_type":"none"}
```

## 4. 字段说明

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| utt_id | 是 | 样本唯一 ID |
| audio | 是 | 音频相对路径 |
| text | ASR/翻译/纠错必需 | 转写文本或目标文本 |
| language | 小语种/混合语种必需 | 语种代码 |
| speaker_id | 声纹必需 | 说话人 ID |
| channel | 跨信道必需 | 采集通道 |
| noise_type | 增强建议 | 噪声类型 |
| clean_audio | 增强可选 | 干净语音相对路径 |
| target_text | 翻译/纠错可选 | 目标语种文本或纠错后文本 |
| intent | 交互可选 | 意图标签 |
| slots | 交互可选 | 槽位标注 |

## 5. 音频要求

- 格式：wav、flac 或 mp3，推荐 wav
- 采样率：推荐 16 kHz 或 48 kHz
- 声道：单声道或多声道均可，多声道需在标注中声明
- 单条时长：建议 1 秒到 30 秒
