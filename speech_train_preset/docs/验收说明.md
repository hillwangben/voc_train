# 语音类垂直训练资产包验收说明

## 1. 结构验收

- 资产包包含 `alg`、`env`、`dataset`、`model` 四类目录。
- 每个资产目录包含 `INFO.ini`。
- 算法资产包含 `config.yaml`、`train.sh`、`eval.sh`、`convert.sh`、`service.sh`。
- 算法脚本不依赖固定绝对路径。

## 2. 镜像验收

- 镜像可在 Linux + Docker >= 20.10 环境运行。
- 镜像内安装 Haikit whl 包。
- 镜像 tag 与 `env/speech_train_all-env/INFO.ini` 中 `image_id` 一致。

## 3. 训练验收

通过修改 `config.yaml` 中 `parameters.task_type` 验证不同任务：

- `asr`
- `noise_enhancement`
- `cross_channel_asr`
- `low_resource_asr`
- `code_switch_asr`
- `speaker_verification`
- `speech_interaction`
- `speech_translation`
- `speech_correction`

训练任务应能输出：

- 训练日志
- checkpoint 或模型文件
- 训练指标
- 可追溯的训练参数

## 4. 评估指标

| 任务 | 推荐指标 |
| --- | --- |
| ASR/转写 | WER、CER |
| 语音增强 | SNR、PESQ、STOI |
| 跨信道 ASR | WER、CER、通道鲁棒性对比 |
| 小语种 ASR | WER、CER、低资源集性能 |
| 混合语种 ASR | WER、CER、语种切换准确率 |
| 声纹识别 | EER、FAR、FRR |
| 语音交互 | 意图准确率、槽位 F1 |
| 语音翻译 | BLEU、COMET 或 chrF |
| 语音纠错 | Precision、Recall、F1 |
