## 1. 资产结构验收

### 1.1 顶层 4 个固定子目录(《资产包准备说明》要求)

```text
speech_train_preset/
├── alg/         # 算法工程(规范固定)
├── env/         # 环境镜像(规范固定)
├── dataset/     # 数据集(规范固定)
└── model/       # 模型(规范固定)
```

- ✅ 4 个子目录**全部存在**
- ✅ 每个子目录中至少 1 个资产子文件夹,命名遵循 `任务前缀 + 标识 + 类型后缀`
- ✅ 文件夹名 = `INFO.ini` 的 `name` 字段(强制一致)

### 1.2 每个资产子目录的标准结构(《资产包准备说明》通用文件)

| 文件 | 必需 | 说明 |
|---|---|---|
| `INFO.ini` | **是** | 资产元信息(详见 §1.3) |
| `README.md` | 否 | 中文说明 |
| `PROFILE.jpg` | 否 | 资产封面 |

### 1.3 INFO.ini 字段

| 类型 | 通用字段 | 专属字段(按需) |
|---|---|---|
| **所有** | `[base] name / version / tags / description` | — |
| **env** | 同上 | `image_id`(Docker 镜像完整地址) |
| **algorithm (alg)** | 同上 | `train_image` / `evaluate_image` / `adapt_image`(训练/评估/适配环境镜像) |
| **dataset** | 同上 | (无专属字段,zip 与 INFO.ini 同目录) |
| **model** | 同上 | `algorithm` + `algorithm_version` + `dataset` + `dataset_version`(关联时有) |

## 4. 集成使用说明(平台接入步骤)

### 4.1 平台导入顺序(《训练平台集成使用说明》§3 同步)

1. **导入环境资产**:解析 `env/speech_train_all-env/INFO.ini: image_id`
2. **导入算法资产**:解析 `alg/speech_train_all-alg/INFO.ini: train_image / evaluate_image / adapt_image`
3. **导入数据集资产**:解压 `dataset/speech_train_sample-dataset/speech_train_sample-dataset.zip`
4. **导入模型资产**:解压 `model/<具体-model-资产>/model.zip` 或经 `model/<asset>/model/<name>/` 软链

### 4.2 容器内挂载约定

| 容器路径 | 来源(本资产包) | 说明 |
|---|---|---|
| `/workspace/algorithm` | `alg/speech_train_all-alg/main/` | 算法工程(脚本、源码、config.yaml、haikit/) |
| `/workspace/input` | `dataset/speech_train_sample-dataset/` 解压后 | 音频与 JSONL 标注 |
| `/workspace/model` | `model/<具体-资产>/` | 单个 model 资产(9 个可选) |
| `/workspace/output/{train,evaluate,adapt}` | (平台侧输出目录) | 训练/评估/适配产物 |

### 4.3 平台任务启动示例(ASR 训练)

```bash
TASK_TYPE=asr \
BACKEND=vosk_small \
DATA_DIR=/workspace/input \
MODEL_DIR=/workspace/model/asr_vosk_small-cpu-model \
SAVE_DIR=/workspace/output/train \
PYTHON_BIN=python3 \
bash /workspace/algorithm/train.sh
```

> TASK_TYPE 与 BACKEND 共同决定:算法包 `config.yaml` 的 `parameters.task_type` 选择流程,
> BACKEND 选择真实模型后端(可选,默认按 `default_backend_for_task` 自动选)。

### 4.4 4 类平台任务入口

| 平台任务 | 启动脚本 | 真实后端(默认) |
|---|---|---|
| train | `main/train.sh` | task_type 默认 backend |
| evaluate | `main/eval.sh` | task_type 默认 backend |
| adapt | `main/convert.sh` | task_type 默认 backend |
| service | `main/service.sh` | task_type 默认 backend |

### 4.5 产物采集

| 路径 | 内容 |
|---|---|
| `runs/all_cpu_tasks/<task_type>/train/checkpoint.json` | 训练快照 |
| `runs/all_cpu_tasks/<task_type>/train/train_metrics.json` | 训练指标(loss/epochs/sample_count) |
| `runs/all_cpu_tasks/<task_type>/evaluate/metrics.json` | 评估指标(wer/cer/accuracy/f1 等) |
| `runs/all_cpu_tasks/<task_type>/summary.json` | 单任务汇总 |
| `runs/all_cpu_tasks/summary.json` | 10 任务总报告 |
| `<SAVE_DIR>/haikit_report.jsonl` | haikit SDK 上报(metrics + artifact) |

## 7. 已知限制与扩展方向

| 限制 | 说明 | 扩展 |
|---|---|---|
| ASR WER 普遍 1.0 | 合成 wav 是静音,真实 ASR 模型识别不出 | 替换数据集为真实录音 wav |
| sherpa_onnx_int8 是中文模型 | code_switch_asr 实际解码中文 | 多语种可换 sherpa 多语种 ONNX |

| noise_enhancement 用 rnnoise 代理 SNR | DeepFilterNet API 复杂,部分环境降级 | 改用 torchaudio + 真实 PESQ 库 |

## 8. 常见问题

### 8.1 平台没有 `python` 命令
脚本默认 `PYTHON_BIN=python3`,可通过环境变量覆盖:
```bash
PYTHON_BIN=/opt/conda/bin/python bash train.sh
```

### 8.2 真实模型权重不在工程内
当前 9 个真实后端权重已全部缓存到 `model/real_cpu_models/`,无需联网下载。
如需新增,放入对应 `<backend>-cpu-model/model/<name>/` 软链目标即可。

### 8.3 数据集过小无法训练真实模型
当前每类 50 条是**平台验收**最小集,生产可替换为 5w+ 真实数据集。
但 ASR/增强/翻译任务在 50 条下也能验证**模型加载与推理通路**,不会因样本小而失败。

### 8.4 真实推理失败如何降级
`backends.py:is_backend_available()` 检查权重 + Python 包,失败时 `default_backend_for_task` 返回 `cpu_reference`。
可观察 `metrics.json: backend` 字段确认是否降级。
