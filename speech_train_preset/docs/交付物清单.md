# 语音类垂直训练容器交付物清单

## 1. 交付策略

采用方案2：一个统一语音训练容器承载全部语音类垂直训练能力。平台通过算法包 `config.yaml` 中的 `task_type` 参数选择具体训练任务。

该方案适用于首次集成交付，优点是镜像数量少、平台接入简单、训练入口统一。后续如需降低镜像体积或隔离依赖，可演进为多容器方案。

## 2. 资产清单

| 类型 | 资产名称 | 目录 | 说明 |
| --- | --- | --- | --- |
| 算法 | speech_train_all_in_one | alg/speech_train_all_in_one | 统一语音训练算法工程 |
| 环境 | speech_train_all-env | env/speech_train_all-env | 统一训练环境镜像 |
| 数据集 | speech_train_sample-dataset | dataset/speech_train_sample-dataset | 示例语音训练数据集 |
| 模型 | speech_train_base-model | model/speech_train_base-model | 语音基础预训练模型 |

## 3. 容器镜像

推荐镜像命名：

```text
cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1
```

如需按智能资产规范中的原始仓库前缀命名，可使用：

```text
10.0.64.41/engine/ubuntu22.04-python3.10-cuda12.1-torch2.1-a100:speech-train-all-v1
```

## 4. 任务类型

| task_type | 对应需求 |
| --- | --- |
| asr | 语音识别、语音转写 |
| noise_enhancement | 复杂噪声语音增强 |
| cross_channel_asr | 跨信道连续语音识别 |
| low_resource_asr | 小语种连续语音识别 |
| code_switch_asr | 混合语种连续语音识别 |
| speaker_verification | 声纹识别 |
| speech_interaction | 语音智能交互 |
| speech_translation | 多语言语音翻译 |
| speech_correction | 语音纠错 |

## 5. 平台入口

算法包提供四类平台任务入口：

- `train.sh`：训练入口
- `eval.sh`：评估入口
- `convert.sh`：模型格式转换和适配入口
- `service.sh`：在线服务入口
