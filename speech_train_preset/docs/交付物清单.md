# 语音类垂直训练容器交付物清单

## 1. 交付策略

采用方案2：一个统一语音训练容器承载全部语音类垂直训练能力。平台通过算法包 `config.yaml` 中的 `task_type` 参数选择具体训练任务。

该方案适用于首次集成交付，优点是镜像数量少、平台接入简单、训练入口统一。当前交付物已按 CPU-only 离线验收方式整理，并在工程内缓存开源 CPU 小模型权重或离线资源。

## 4. 容器镜像

当前工程已提供环境离线构建包：

```text
env/speech_train_all-env/speech_train_all-env.tar.gz
```

推荐镜像命名：

```text
cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cpu:speech-train-all-v1
```

如需按智能资产规范中的原始仓库前缀命名，可使用：

```text
10.0.64.41/engine/ubuntu22.04-python3.10-cpu:speech-train-all-v1
```

说明：当前交付物不强绑定 GPU/CUDA 镜像，模型和脚本均按 CPU-only 验收。若目标平台必须接收 Docker image tar，可在平台基础镜像策略确定后基于 `env/speech_train_all-env/Dockerfile` 构建镜像，并导出到同目录。

## 7. 平台入口

算法包提供四类平台任务入口：

- `train.sh`：训练入口
- `eval.sh`：评估入口
- `convert.sh`：模型格式转换和适配入口
- `service.sh`：在线服务入口

## 8. 自检命令

在 `speech_train_preset` 根目录执行：

```bash
python3 scripts/validate_asset_package.py
```

期望输出：

```text
asset-package-ok
```

完整测试命令：

```bash
python3 -m unittest discover -s alg/speech_train_all_in_one/main/tests -p 'test_*.py'
```
