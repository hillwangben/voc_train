# 统一语音训练容器镜像构建说明

## 1. 基础环境

建议基础镜像：

```text
nvidia/cuda:12.1.1-cudnn8-runtime-ubuntu22.04
```

建议软件版本：

| 组件 | 版本 |
| --- | --- |
| Python | 3.10 |
| PyTorch | 2.1+ |
| CUDA | 12.1 |
| Docker | >= 20.10 |
| Haikit | 按平台提供 whl 包安装 |

## 2. 建议内置能力

容器内建议预置以下语音训练框架或脚本依赖：

- ASR：Paraformer、Whisper、Wav2Vec2、Conformer 或同类模型训练脚本
- 语音增强：DNSMOS、Demucs、SepFormer、MetricGAN+ 或同类模型训练脚本
- 声纹识别：ECAPA-TDNN、ResNet speaker embedding 或同类模型训练脚本
- 语音翻译：Whisper translation、SeamlessM4T 或同类模型训练脚本
- 语音纠错：文本纠错、热词纠错、标点恢复、领域词典纠错脚本
- 语音交互：ASR 后接意图识别、槽位抽取、指令分类脚本

## 3. 镜像命名

平台资产包说明要求镜像提前 tag 成平台仓库前缀：

```bash
docker tag speech-train-all:v1 cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1
```

导出镜像：

```bash
docker save cetc-harbor.registry.com:30003/exp/ubuntu22.04-python3.10-cuda12.1-torch2.1:speech-train-all-v1 | gzip > speech_train_all-env.tar.gz
```

将导出的 `speech_train_all-env.tar.gz` 放入：

```text
env/speech_train_all-env/
```

## 4. 容器内约定目录

```text
/workspace/algorithm
/workspace/input
/workspace/output
/workspace/model
/workspace/config
```

算法脚本应避免使用绝对业务路径，启动脚本通过当前工程目录自动定位。
